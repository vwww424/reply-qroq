4 API — кожне робить свою роботу

Кожен етап має свій ключ Groq (можна з різних акаунтів, тоді ліміти безкоштовного тарифу не перетинаються) і свою модель. Обов'язкова лише генерація. Інші етапи можна вимкнути або залишити без ключа, і розширення працюватиме без них. Безкоштовний ключ: console.groq.com/keys. Ключі зберігаються лише локально.
