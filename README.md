# X Reply Writer (Groq)

Розширення для Chrome: біля кожного поста в X/Twitter з'являється іконка ✎. Натискаєш, обираєш стиль, і за кілька секунд отримуєш варіанти реплаю українською з оцінками. Найкращий вставляється в поле відповіді, а відправляєш ти сам.

## Встановлення

1. Отримай безкоштовний ключ на <https://console.groq.com/keys>.
2. Відкрий `chrome://extensions`, увімкни **Режим розробника**, натисни **Завантажити розпаковане** і вибери цю папку.
3. Сторінка налаштувань відкриється сама: встав ключ і натисни **Перевірити**.
4. Онови вкладку x.com.

## Як це працює (4 запити до API)

| Етап | Що робить | Модель за замовчуванням |
|---|---|---|
| 1. Контекст | Читає пост із DOM (текст, автор, цитата, alt картинок, попередні пости гілки), повертає суть, тон, слабкі місця, кути для відповіді та переклад | `openai/gpt-oss-20b` |
| 2. Генерація | Пише N варіантів у вибраному стилі, з твоїм «голосом» і списком заборонених слів | `openai/gpt-oss-120b` |
| 3. Грамотність | LanguageTool (справжній спелчекер) + LLM-коректор: орфографія, пунктуація, русизми, суржик. Якщо коректор переписав текст замість виправлення, правку відкидає | `openai/gpt-oss-120b` |
| 4. Оцінка | Суворий критик ставить бали: 🎯 релевантність, 🧠 людяність, 🔥 чи чіпляє, ризик, «загальник», «тригерить автора» | `llama-3.3-70b-versatile` |

Якщо варіанти слабкі (нижче мінімальної оцінки), генерація повторюється із зауваженнями критика (до 3 раундів). Після кожного етапу текст перевіряється локально, без API: заборонені слова, довге тире, «не просто X, а Y», російські літери, компліменти на початку, «а ви що думаєте?», довжина за правилами X.

## Що є в панелі

- 8 стилів (Байт, Своя думка, Незгода, Іронія, Гостре питання, Доповнення, Підтримка з кутом, Жарт). Їх можна редагувати й додавати свої.
- Підказка до конкретного реплаю («зачепи цифру»).
- Редагування тексту прямо в картці з лічильником символів.
- Кнопки «Коротше / Гостріше / Смішніше / Простіше / Інший кут».
- «Вставити в реплай» відкриває відповідь і вставляє текст. Якщо X змінив верстку, текст копіюється в буфер.
- Попередження про чутливі теми (смерть, втрати), щоб випадково не вийшов байт.

## Налаштування

Ключ і моделі для кожного етапу, мова реплаю (укр / англ / як у пості, з перекладом), довжина та ліміт символів (для Premium), стиль «з маленької літери», емодзі/хештеги, **«Про мене» та приклади твоїх твітів** (найсильніше впливає на «авторськість»), список заборонених слів (~280, з `*` для закінчень), пороги оцінки, автовставка, історія (видно в попапі), експорт/імпорт.
